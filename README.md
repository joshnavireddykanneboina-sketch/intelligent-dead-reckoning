# NAVIGEN

**SIH 2026 Problem Statement:** SIH26168

NAVIGEN is an intended AI/ML-based Intelligent Dead Reckoning project for supporting seamless navigation in GNSS-denied environments.

## Architecture

The planned system design, implementation boundaries, and development roadmap are documented in [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Current status

This version is only the initial project foundation. The complete intelligent dead reckoning system is **not implemented yet**.

## Project structure

```text
NAVIGEN/
├── backend/
│   └── main.py
├── data/
├── docs/
├── models/
├── notebooks/
├── tests/
├── README.md
└── requirements.txt
```

## Run the backend entry point

From the project root, run:

```powershell
python backend/main.py
```
